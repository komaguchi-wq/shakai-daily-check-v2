A1 全体像 地図を読む5つの道具

この回は14ページずっと地図を読む。地図は「全部をながめる」と迷うので、5つの道具のどれを使うかを決めてから見る。以後のカードでは「道具②等高線」のように、この名前で呼ぶ。

道具どこを見る何がわかる
①縮尺「1:25000」の表示・物さし、太い等高線の数字実際の長さ＝地図上の長さ×分母（cm→m→km は100・1000で直す）。面積はたて・よこを両方直してからかける
②等高線線の混み方・曲がり方・標高点の数字高い所と低い所、急かなだらか、谷と尾根、川の向き
③方位方位記号（ことわりがなければ上が北）どちらの向きにあるか（8方位）
④地図記号田 ‖・畑 ∨・果樹園 ○・茶畑 ∴・針葉樹林 Λ・神社 ⛩・寺 卍・市役所 ◎ などその土地を何に使っているか（記号は形の由来とセットで）
⑤地形と土地利用の組み合わせ②と④を重ねる扇状地＝果樹園、三角州・低地＝水田や市街地、河岸段丘＝上の段は畑・下の段は水田、台地＝畑や茶、海岸の砂地＝針葉樹林の防砂林

読む順番は毎回同じ5つ。地図は全部を読もうとせず、設問で調べることを決めてから、その場所だけ見る。等高線や記号を追うのは、順番3で場所を囲んだ後にする。

順番やること
1 下見は3つだけどこの・何の地図か／縮尺／方位（地図が2枚なら発行年）。ここでは記号や等高線を追わない
2 設問に印場所の言葉に丸・聞かれ方に線・答えの単位に丸。印をつけたら型（下の表）を決める
3 設問の言葉を地図に置くその場所を囲む。施設の名前は先に記号に直して余白にかく
4 選択肢は1文ずつ○×方位・距離・高さ・記号・ある／ない のどれを確かめる文かを決める。全部の文に○×を書いてから答える
5 確かめ3つ聞かれ方・単位・けた

順番2で決める型は7つ。型ごとに最初の一手が決まっている。

型最初の一手
A 新旧くらべ両方にある目印を2つ決めて見比べる
B 断面図・鳥かん図・写真の向き両はしの高さを先に書く
C 記号のある・なし、正誤文名前を記号に直し、範囲を区切って端から探す

E 高さ・谷と尾根・川の向き形より先に数字で高い側を決める
F 理由を答える（地形と土地利用・災害）地図のどこに何があるかを1つ指してから知識とつなぐ
G 境界・川・昔の流れ・海岸線まっすぐな線は人が作ったもの、境界と川のずれは昔の流れ

A1 2・3・4・5 主曲線と計曲線の間かく 素材文・数値の選択

👀 まず見るところ

【素材文】部品は「5万分の1」「2万5千分の1」と「主曲線／計曲線」。4つのらんを2行2列の表に直して書く → 主曲線を決めれば、計曲線はその5倍で決まる。

📚 前提知識

  • 主曲線＝細い等高線（基本の間かく）。計曲線＝太い等高線で、主曲線5本ごとに1本。標高の数字は計曲線につくことが多い。
  • 2万5千分の1は5万分の1の2倍くわしい地図。くわしい地図ほど等高線の間かくはせまい。

🔍 こう読み解く

  1. 文の順番を確かめる：(2)(3)が5万分の1、(4)(5)が2万5千分の1。どちらも「主曲線→計曲線」の順。
  2. くわしい2万5千分の1から決める。主曲線＝10m → (4)＝ア。計曲線＝10×5＝50m → (5)＝ウ。
  3. 5万分の1は2倍あらいので、主曲線も2倍の20m → (2)＝イ。計曲線＝20×5＝100m → (3)＝エ。
  4. 選択肢のオ（250）はここでは使わない。
              主曲線（細）  計曲線（太）＝主曲線×5
5万分の1         20m          100m
2万5千分の1      10m           50m
答え：2 イ（20）　3 エ（100）　4 ア（10）　5 ウ（50）
🗺 地図のコツ：縮尺が書かれていない地形図でも、太い線（計曲線）どうしの差が50mなら2万5千分の1、100mなら5万分の1と見分けられる。道具①縮尺を出すときの入口になる。

A1 6・7 等高線の間かくと傾斜 素材文・語句の選択

👀 まず見るところ

【素材文】部品は「間かくがせまく、こみ入っている」と「間かくが広い」。間かく＝同じ高さを上がるのに使う横の長さ、と直して書く → せまい＝短い距離で一気に上がる＝急。

📚 前提知識

  • となりの等高線との高さの差は、どこでも同じ（2万5千分の1の主曲線なら10m）。ちがうのは横の長さだけ。

🔍 こう読み解く

  1. 等高線を1本こえるたびに、同じ高さ（たとえば10m）だけ上がる。
  2. 間かくがせまい＝短い横の距離で10m上がる＝坂が急 → (6)＝イ。
  3. 間かくが広い＝長い距離をかけて10m上がる＝なだらか → (7)＝ア。
上から見る   ｜｜｜｜｜        ｜　　｜　　｜
             せまい               広い
横から見る      ／              ＿＿／
               急               なだらか
答え：6 イ（急）　7 ア（なだらか）
🗺 地図のコツ：等高線がびっしり重なって黒っぽい帯に見える所は、がけや急な斜面。河岸段丘の段の境目や、リアス海岸の海ぎわがこれにあたる（A2で使う）。

A1 8・9 谷の等高線と川の流れる向き 素材文＋図・語句の選択

👀 まず見るところ

【素材文】部品は「川は周囲より低くなっている（8）」と「細い線が等高線、太い線が川」。図に「谷」と書き、等高線の＞の先に「高」と書きこむ（直して書く）→ 川の向きが決まる。

📚 前提知識

  • 谷＝等高線が高い方へ食い込む形。尾根＝等高線が低い方へ張り出す形。同じ「＞」の形でも、どちらが高いかで谷にも尾根にもなる。
  • 水は高い所から低い所へ流れる。だから川は谷の中を、食い込んだ先（上流）から開いた方（下流）へ流れる。

🔍 こう読み解く

  1. 本文「川は周囲より低くなっている（8）を流れます」→ まわりより低く、川が流れる所＝谷 → (8)＝ア。
  2. 紙面の図を見る。細い線はどれも「＞」の形で、とがった先が太い線の上にあり、右を向いている（図の❶）。
  3. 谷では等高線が高い方へ食い込むので、＞の先＝右が高い（上流）、開いた方＝左が低い（下流）。
  4. 川は高い右から低い左へ流れる（図の❷）→ (9)＝ア「右から左」。吹き出し「川の流れ」が右端についているのは名前の札で、向きとは関係ない。
 谷  ：＞の先が高い方 → 右が上流
 流れ：左（低） ←━━━ 右（高）＝右から左
 尾根：同じ＞でも、先は低い方（ふもと）を向く
答え：8 ア（谷）　9 ア（右から左）
🗺 地図のコツ：＞の形だけでは谷か尾根かは決まらない。先に標高点の数字や川の線で「どちらが高いか」を決めてから形を読む。高い方へ食い込んでいれば谷＝水が集まる所。

A1 10・11 鳥瞰図と主題図 知識問題

(10) 鳥瞰図＝鳥が空から見下ろすように、高い所からある方向をななめに見た形でかいた地図。(11) 主題図＝目的に合わせてのせる情報をしぼった地図で、土地利用図・地質図・人口分布図などがその仲間。地形図のように、地形・土地利用・建物などをまんべんなくのせる地図は一般図という。

NS-01 A2（1〜2ページ・さまざまな地図）

A2 全体像 4枚の地図と地形

4枚とも、地図の「どこを見ればその地形だとわかるか」がつかめれば、空らんは文から決まる。順番は 下見（どこの地図・縮尺・方位）→ 設問に印 → 設問の言葉を地図に置く → 1文ずつ○× → 確かめ。この4枚には縮尺と方位の表示がないので、下見は文の1行目「○○の一部」で場所を決めるだけでよい。空らんの前後の言葉（「沖まで水深のない」「階段状」など）に印をつけてから、その言葉が指す所だけを地図で見る。地図で見る手がかりは、海岸線の形・等高線の混んだ帯・記号のならびの3つ。

地図手がかりになる形地形土地利用（記号）型
(1) 九十九里浜海岸線がほぼまっすぐ・砂浜の点々・等高線がない砂浜海岸・海岸平野海ぞいに針葉樹林 Λ、平野に田 ‖・畑 ∨①② G／③④ C／A F

(3) 沼田市川と平行に、等高線の混んだ帯が何段も河岸段丘低い段＝田 ‖、高い段＝畑 ∨・果樹園 ○⑧ E／⑨ C
(4) 甲府盆地山の出口から弧をえがく等高線扇状地一面の果樹園 ○⑩ E

型：G＝海岸線の形／C＝記号のある・なし、正誤文／E＝高さ（標高点の数字と等高線）／F＝理由を答える（地形と土地利用・災害）。

A2 (1)①② 九十九里浜の海と漁 資料問題＋素材文・語句

👀 まず見るところ

【素材文】部品は「沖までそれほど水深のない」（①）と「大きな漁港がつくりにくい」（②）。①は地形の言葉に直して書く。港がつくれないなら、浜から網を引く漁と決まる。

📚 前提知識

  • 遠浅＝岸から沖まで、浅い海が長く続くこと。潮流で運ばれた砂がたまる砂浜海岸に多い。
  • 地引網＝沖に網を張り、浜から大勢で引き上げる漁。船をつける大きな港がなくてもできる。九十九里浜ではいわしをとった。

🔍 こう読み解く

  1. 正体を1行：九十九里浜（千葉県）の一部。地図の右側の灰色が海、その手前の細かい点々が砂浜。
  2. 海岸線を見る：地図の右端を上から下まで、ほとんど曲がらずにまっすぐ（図の❶）。入り江も岬もなく、船を波から守る湾がない → 本文の「大きな漁港がつくりにくい」と合う。
  3. ①：「沖まで水深のない海」をひとことで → 遠浅。
  4. ②：港がいらない漁＝浜から網を引く → 地引網。海ぞいの道に「八斗納屋」「中里納屋」「幸治納屋」と「納屋」のつく地名が並ぶ（図の❷）のは、浜で網や道具をしまう小屋から集落ができたためとされる。
答え：① 遠浅　② 地引(き)網
🗺 地図のコツ：海岸線がまっすぐで砂浜の点々が続けば砂浜海岸、ギザギザで等高線が海ぎわまで混んでいればリアス海岸。海岸線の形が最初の手がかりになる。

A2 (1)③・A 海ぞいの並木の役目 資料問題＋素材文・語句と選択

👀 まず見るところ

【資料問題】部品は「海岸沿いに（③）葉樹林の並木」と、地図の砂浜のすぐ内側に並ぶ記号 Λ。Λ＝針葉樹林。砂浜の内側に林を置く理由＝飛んでくる砂をふせぐ、と決まる。

📚 前提知識

  • 地図記号 Λ＝針葉樹林（とがった葉の木を横から見た形）。広葉樹林は丸い形の記号。
  • 砂浜海岸では海風が砂を内陸へ運ぶ。これを止める林が防砂林（防風林をかねる）で、クロマツなどの針葉樹が多い。

🔍 こう読み解く

  1. 地図の右側、砂浜の点々のすぐ内側（左）を拡大して見る。「自転車専用道路」と家並みの間の細長い帯に、Λ の記号が海岸線にそって点々と続く（図の❶。砂浜は❷）＝針葉樹林 → ③＝針。
  2. A は「なぜ海ぞいに並木があるのか」。ここは砂浜海岸なので、風で飛ぶ砂が畑や家に入るのを止めるため → エ。
  3. 残りを消す：ウ「強い波や海流から保護」→ 林で波は止められない（それは堤防の役目）。イ「木材を得る」→ 並木を植えた目的ではない。ア「海水浴客の休けい」→ 海岸ぞいに長く続く林の理由にならない。
答え：③ 針　A エ
🗺 地図のコツ：記号を見つけたら「なぜそこにあるか」を地形と結ぶ（道具⑤）。砂浜のすぐ内側に帯のように並ぶ Λは、防砂林・防風林と読める。

👀 まず見るところ

【資料問題】部品は「東京駅西側の気候」と条件「春・夏・秋・冬のいずれかを入れ、下線」。図2の正体は東京駅周辺の地図で、海（東京湾）は右下＝南東。海→ビル群→西側と矢印を図に置けば、風の話と決まる。

📚 前提知識

  • 夏の昼は、あたたまりやすい陸へ海から風がふく（海風）。また、日本の夏の季節風は太平洋から南東の風としてふく、と習う。どちらも東京では海（東京湾）の方向から来る風になる。
  • ヒートアイランド現象＝都市の中心部の気温がまわりより高くなること。風が通らないと熱が逃げずにこもる。

🔍 こう読み解く

  1. 図2の題「地点1周辺の地図」と、方位の記号がないこと（＝上が北）を確かめる。東京駅は地図の上半分の左寄り、皇居のすぐ東にある（図の❶）。
  2. 海を探す。地図の右下に晴海・豊洲・月島などの埋め立て地と水面が広がる。東京駅から見て海は南東（図の❷）。
  3. 東京駅と海の間には、銀座・築地・新橋にかけて建物がぎっしり並ぶ。海からの風は、このビル群（図の❸）に正面からぶつかってから西側（図の❹）へ届く。
  4. 海から風がふきこむ季節＝夏、と決めて「夏」に下線。あとは「風をさえぎる → 西側に熱がこもる → ヒートアイランド」と因果の順に並べる。

✍️ 答案の組み立て

  1. 要素A（季節と風）：夏に海側からふきこむ風。海の位置は図2の右下から拾う。
  2. 要素B（ビル群のはたらき）：建ちならぶビル群がその風をさえぎる。
  3. 要素C（西側の結果）：東京駅の西側で熱がこもり、ヒートアイランド現象がおこる。
模範解答：建ちならぶビル群は、夏に海側からふきこむ風をさえぎってしまうため、東京駅の西側では熱がこもり、ヒートアイランド現象がおこる。
🗺 地図のコツ：風や気候を聞かれたら、まず地図の中で海がどちらにあるかを決める。ことわりがなければ上が北なので、右下の海＝南東の海になる。
