WC 1(2)①②③ 地形図と地形の説明 資料問題・記号選択

👀 まず見るところ

【資料問題】部品は3つの地形図の正体＝「水田が広がる平地／三日月の形の湖／扇形に広がる等高線」を1行ずつ書く。説明文の「三角州」「三日月湖」「扇状地」と結べば、知識がなくても地図の形だけで決まる。

📚 前提知識（あれば答え合わせに使う）

  • 扇状地＝川が山地から平地に出るところ。土砂が扇の形に積もり、水はけがよいので果樹園。等高線が扇の形に広がる。
  • 三角州＝川の河口。細かい土砂が積もった低い平地で、水が得やすいので水田。
  • 三日月湖＝蛇行した大きな川の流れの一部が取り残された湖（石狩川の流域に多い）。

🔍 こう読み解く

  1. ①は海と川にはさまれた平らな土地に、田の記号が規則正しくしきつめられている → 河口の低地＝三角州 → イ。
  2. ②は川のわきに三日月の形の水面が残っている → 三日月湖＝ウ。
  3. ③は山のふもとから等高線が扇のように広がっている → 扇状地＝ア。果樹園の記号は印刷が小さくて読みにくいので、等高線の形で決める。
答え：① イ　② ウ　③ ア
今回：① イ ○　② ウ ○　③ ア ○。3つの地形を形で見分けられている。

WC 1(3)① 縮尺が2倍になると面積は 条件文・正誤

👀 まず見るところ

【条件文】部品は「同じ大きさの地形図」と「縮尺が2倍」。「縦も横も2倍」に直して書く → 面積は2×2＝4倍（同じ大きさの紙に入る範囲なら4分の1）。どちらの向きでも「2倍」にはならないので×と決まる。

📚 前提知識

  • 縮尺は長さの比。長さが2倍になれば面積は4倍、長さが半分なら面積は4分の1。
  • 同じ大きさの紙なら、縮尺が大きい（2万5千分の1）ほどせまい範囲を細かく、縮尺が小さい（5万分の1）ほど広い範囲を表す。

🔍 こう読み解く

  1. 「2倍」が長さのことか面積のことかを分ける。縮尺は長さ。
  2. 長さ2倍 → 面積は縦2倍×横2倍＝4倍。文の「面積も2倍」が合わない → ×。
答え：×
今回：× ○。

WC 2(2)① 面積が正しい世界地図 資料問題・図法

👀 まず見るところ

【資料問題】部品は聞かれ方「面積が正しく」に線。3つの図の正体を1行ずつ＝①だ円（モルワイデ）／②長方形で緯線の間がひらく（メルカトル）／③円で中心から広がる（正距方位）。面積が正しいのは①。

📚 前提知識

  • モルワイデ図法＝だ円。面積が正しい（分布図に使う）。
  • メルカトル図法＝長方形。角度が正しく航海図に使うが、高緯度ほど面積が大きく見える（グリーンランドが実際より大きい）。
  • 正距方位図法＝円。中心からの距離と方位が正しい（航空図）。中心から遠いほど形がゆがむ。

🔍 こう読み解く

  1. ②は南極が横に大きく引きのばされている → 面積は正しくない。
  2. ③は外側の大陸が引きのばされている → 面積は正しくない。
  3. 残った①のだ円＝モルワイデ図法。面積が正しい。
答え：①
今回：① ○。
