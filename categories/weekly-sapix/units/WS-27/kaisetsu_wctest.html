WC 1(1)①②③④ 衆議院の選挙制度と定数 素材文・語句と数字

👀 まず見るところ

【素材文】設問は「空らんに語句や数字」。部品は1文目の「衆議院議員総選挙」と、そのあとの「小選挙区」「比例代表」「ブロック」に丸 → 2つの選挙を組み合わせた制度の名前が①、小選挙区の数が②、ブロック数が③、比例代表の定数が④と、丸の数だけ答えが決まる。

📚 前提知識

  • 衆議院は小選挙区比例代表並立制。定数465＝小選挙区289＋比例代表176。
  • 比例代表は全国を11ブロック（北海道・東北・北関東・南関東・東京・北陸信越・東海・近畿・中国・四国・九州）に分ける。
  • 衆議院は任期4年で解散がある。数字は「465＝289＋176」と足し算の形で持つと、1つ忘れても残りから出せる。

🔍 こう読み解く

  1. ①：小選挙区と比例代表を同時に行う → 小選挙区比例代表並立制。「並立」は2つの選挙が並んで立つ、という意味。
  2. ②「選挙区から1名ずつ」→ 小選挙区の数＝289。③ブロック＝11。④比例代表の合計＝176。
  3. 検算：289＋176＝465になれば、数字の取りちがえがない。
答え：① 小選挙区比例代表並立　② 289　③ 11　④ 176
今回：① 小選挙区比例代表並立 ○／② 289 ○／③ 11 ○／④ 176 ○。制度名も3つの数字もそろっていた。

WC 1(1)⑤⑥ 比例代表の投票先と当選の決め方 素材文・語句

👀 まず見るところ

【素材文】⑥の部品は空らんの直前「候補者名簿の上位から順に当選する」。「名簿」が式の名前にそのまま入る → 拘束名簿式と決まる。その前の「得票数に応じて議席数が決められ」はドント式の説明で、⑥の空らんにはつながっていない。参議院の文の「非（⑥）式」も確かめに使える。

📚 前提知識

  • 参議院の比例代表：政党名でも候補者名でもよく、候補者名の票が多い順に当選＝非拘束名簿式。「非」は、名簿の順番を政党が縛らない、という意味。
  • ドント式は「議席の数をどう分けるか」の計算方法。「だれから当選するか」を決める式ではない。

🔍 こう読み解く

  1. ⑤：「支持する（⑤）の名前を書いて投票」「各（⑤）の議席数」→ 政党。
  2. ⑥：空らんの直前を読む。「候補者名簿の上位から順に」→ 名簿の順番で縛る＝拘束名簿式。
  3. 確かめ：参議院の文は「非（⑥）式」。「非ドント式」という言葉はないので、ここでも⑥＝拘束名簿に決まる。
答え：⑤ 政党　⑥ 拘束名簿
今回：⑤ 政党 ○／⑥ ドント ×。部品を拾えなかった＝空らんの直前「名簿の上位から順に」でなく、その前の「得票数に応じて」に反応した。空らんの直前の言葉に丸をつけてから書く。

WC 1(1)⑦⑧ 参議院の1回の選挙で選ばれる人数 素材文・数字

👀 まず見るところ

【素材文】部品は「参議院」と、2回出てくる「1回の選挙で」。参議院は3年ごとに半数を選び直すので、「1回の選挙で」は「定数248の半分＝124」と直して書く → 124を選挙区と比例代表に分けた数が⑦⑧。

📚 前提知識

  • 参議院の定数は248。任期6年で解散はなく、3年ごとに半数（124名）を改選する。
  • 124名の内わけは選挙区74名＋比例代表50名。選挙区は原則として都道府県ごと（鳥取・島根、徳島・高知は2県で1つの合区）。比例代表は全国を1つの区にする。
  • 衆議院の「465＝289＋176」とセットで、参議院は「248＝（74＋50）×2」と式の形で持つ。

🔍 こう読み解く

  1. 「1回の選挙で」→ 248÷2＝124。ここを余白に書く。
  2. 選挙区は74、「全国を1つの比例代表区」の比例代表は50。74＋50＝124になれば合っている。
答え：⑦ 74　⑧ 50
今回：⑦⑧ 空らん ×（赤の✓）。余白に「248」と書いてあり、定数までは出ていた。部品の形を直さなかった＝「1回の選挙で」を÷2に直して124と書けば、あとは74と50に分けるだけだった。

WC 1(2)①② 国に対する直接民主制 素材文・図の穴うめ

👀 まず見るところ

【素材文】設問は「直接民主制が採用されている例」。部品は図の箱の「最高裁判所裁判官の」「憲法改正の」と、矢印の先の「国」に丸 → 国民が国に対して直接行うのは、裁判官を審査することと、憲法改正を投票で決めることの2つ。

📚 前提知識

  • 国民審査：最高裁判所の裁判官がふさわしいかを、任命後はじめての衆議院議員総選挙のときに国民が審査する。やめさせたい裁判官に×をつける。
  • 国民投票：憲法改正は、衆参それぞれ総議員の3分の2以上の賛成で国会が発議し、国民投票で過半数の賛成があれば成立する。
  • 直接民主制の3つの例＝国民審査・国民投票・（地方の）直接請求権。図はこの3つをそのまま並べている。

🔍 こう読み解く

  1. 「裁判官」＋国民 → 国民が裁判官を審査する＝国民審査。
  2. 「憲法改正」＋国民 → 国民が投票で決める＝国民投票。
  3. 取りちがえやすい2語なので、「裁判官＝審査」「憲法＝投票」と丸の横に書く。
答え：① 国民審査　② 国民投票
今回：① 国民審査 ○／② 国民投票 ○。

WC 2(1)①②③⑥ 仕事の言葉から省の名前を決める 素材文・漢字指定

👀 まず見るところ

【素材文】設問は「省庁の名前を漢字で」。部品は各文の仕事を表す言葉に1〜2語ずつ丸：①「予算案」「税制」、②「社会保障」「労働」、③「教育」「科学技術」、⑥「地方自治」「消防」「通信」 → 丸の言葉が省の名前の一部になっているもの（労働・教育・科学）から決まり、名前に入っていない⑥だけ知識で決める。

📚 前提知識

🔍 こう読み解く

  1. 言葉が名前に入っている省から埋める：②労働→厚生労働省、③教育・科学→文部科学省。

WC 2(1)④ 工業・経済・貿易を受け持つ省 素材文・漢字指定

WC 2(1)⑤ 国土の開発と保全を受け持つ省 素材文・漢字指定

👀 まず見るところ

【素材文】部品は「国土」と、設問の「漢字で」。「国土」が名前に入る省は国土交通省の1つだけ → 答えはすぐ決まるので、残る仕事は4字を正確に書くこと。「交通」の交は、交差点の「交」。

📚 前提知識

WC 2(2)①②⑥⑦ 社会保障の4本柱 素材文・表の穴うめ・漢字指定

👀 まず見るところ

【素材文】設問は「日本の社会保障制度」の表。部品は左の列の空らんが4つあることと、右の説明の言葉：①「生活保護」、②「保険」が3つ、⑥「児童、高齢者、障害者」、⑦「保健所」「感染症」 → 左の列＝社会保障の4本柱。先に4つ（社会保険・公的扶助・社会福祉・公衆衛生）を書き出してから、説明に当てはめる。

📚 前提知識

  • 社会保障の4本柱：社会保険（医療・年金・介護・雇用・労災）／公的扶助（生活保護）／社会福祉（児童・高齢者・障害者・母子家庭への支援や施設）／公衆衛生（保健所・感染症対策・生活環境）。
  • 言葉の意味で分ける。「保険」は加入してお金を出し合い、必要になったときに受け取る。「扶助」は国がお金を出して生活を助ける。「福祉」は困っている人を支えるサービスや施設。「衛生」は病気を防いで健康を守る。
  • 設問は漢字指定。公的扶助の「扶」、公衆衛生の「衆」「衛」は書いて確かめる字。

🔍 こう読み解く

  1. 表の左列は4つ。先に「社会保険・公的扶助・社会福祉・公衆衛生」と4つ書く。
  2. ①生活保護＝お金で助ける → 公的扶助。②「保険」が3つ並ぶ → 社会保険。
  3. ⑦保健所・感染症 → 公衆衛生。残った⑥児童・高齢者・障害者・母子家庭の保護と施設 → 社会福祉。4つ書き出せば、⑥は残りで決まる。
答え：① 公的扶助　② 社会保険　⑥ 社会福祉　⑦ 公衆衛生
今回：① 公的扶助 ○／② 社会保険 ○／⑥ 空らん ×（赤×）／⑦ 公衆衛生 ○。⑥は知識＝4本柱の4つ目が出なかった。3つ書けた時点で「残り1つは何か」と探せば、児童・高齢者・障害者の支援＝福祉にたどり着けた。

WC 2(2)③④⑤ 社会保険の3つ 素材文・表の穴うめ・漢字指定

👀 まず見るところ

【素材文】部品は右の説明の「医療費」、「20歳以上」＋高齢になった際にお金、「40歳以上」＋（⑤）が必要となった際にサービス。年齢の数字がそのまま見分け方になる → 20歳＝年金、40歳＝介護。⑤は空らんが2回出てくるので、2か所に同じ語を入れて文が通るかで確かめる。

  • 年金保険（国民年金）：20歳以上60歳未満の国民が加入し、高齢になると年金を受け取る。
  • 介護保険：2000年に始まった制度。40歳以上が加入し、介護が必要になったとき（主に65歳以上）にサービスを受ける。
  • 社会保険にはほかに雇用保険・労災保険があるが、表にあるのはこの3つ。

🔍 こう読み解く

  1. ③「医療費や治療費の一部を国が負担」→ 医療。
  2. ④「20歳以上」「高齢になった際にお金」→ 年金。
  3. ⑤「40歳以上」「（⑤）が必要となった際にさまざまなサービス」→ 介護。「介護が必要となった際に」と読んで文が通れば合っている。
答え：③ 医療　④ 年金　⑤ 介護
今回：③ 医療 ○／④ 年金 ○／⑤ 介護 ○。
