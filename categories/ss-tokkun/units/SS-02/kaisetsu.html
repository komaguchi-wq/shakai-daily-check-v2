A1（1〜2ページ・歴史の資料読解）

まず全体像 A1は「資料読解型」6問

A1は地図・戸籍・位置図・帯グラフ・棒グラフ・表と、資料の種類を変えながら「資料の読み取り×知識」を試す大問です。時代は古墳→奈良（律令）→室町→江戸前期→江戸後期→明治と、ほぼ年代順に並んでいます。

6問に共通する解き方の型

  1. 設問の指示語に印をつける：「正しいもの」「誤っているもの」「漢字1字」「解答らんの形式にしたがって」。(5)と(6)はここで失点しやすい。
  2. 資料の凡例・単位・軸を先に読む：地図の凡例、グラフの目盛り（%か件数か）、横軸の年。本文より先に読む。
  3. 資料から「事実」を1つずつ取り出す：「●は奈良と岡山にある」「Aは18→41→54%で増えている」のように、自分の言葉で言い換える。
  4. 知識と結びつける：取り出した事実を、知っている出来事・年代・地名と対応させる。
  5. 選択問題は消去法：資料の反例が1つあれば断定文（「のみ」「見られない」）は×にできる。

園子さんの自由研究「日本を訪れた外国人の歴史」という1本のレポートに、古墳時代から昭和までの下線部①〜⑲がつけられ、そこから20問が出ます。テーマは一貫して「外国人・外国との関係」。逆にいえば、日本史の対外関係を時代順に1周する大問です。各2点×20問＝40点。

  1. 下線部の「時代」を先に確かめる：表の左はしに時代名が書いてある。設問は「この時代のできごと」と聞いてくるので、時代を取りちがえるとまるごと落とす（(6)(8)(16)がこの型）。
  2. 「正しいもの」か「正しくないもの」かに印をつける：B3は「正しくないもの」を選ぶ問題が7問中6問と圧倒的に多い。ふだんのくせで正しい文を選ばないこと。

(1) 空らん① 外国人観光客が増えた理由 適文選択・経済

前提知識

  1. 円安＝円の価値が下がること（1ドル＝100円→150円）。円高＝円の価値が上がること。
  2. 円安のとき、外国人にとって日本の旅行は安くなる（＝訪日客が増える）。日本人の海外旅行や輸入は高くなる。
  3. 関税＝輸入品にかける税。旅行者の増減とは直接結びつかない。

読み解きの手順

  1. 空らんの前後を読む：「コロナの影響がなくなったことや、①ことによって、多くの外国人観光客が日本を訪れています」＝訪日旅行が増えた理由を入れる。
  2. ア・イの関税は「モノの輸入」の話→観光客の増減の理由にならない→×
  3. ウ「円高」→外国人には日本旅行が高くなる→逆→×
  4. エ「円安」→外国人の持つドルなどの価値が相対的に上がり、旅行費用が安くなる→○
答え：エ
コツ：円安・円高は「だれにとって得か」で覚える。円安＝輸出企業と訪日外国人が得、円高＝輸入と海外旅行が得。

(2) 下線部② 朝鮮半島から移り住んだ人々 語句記述・漢字3字

前提知識

  1. 渡来人＝古墳時代ごろ、朝鮮半島や中国から日本に移り住んだ人々。
  2. 伝えたもの＝須恵器・機織り・土木や鉄の技術・漢字・儒教など。仏教の伝来（6世紀）にも関わる。
  3. 「帰化人」という古い言い方もあるが、入試では「渡来人」で答える。

読み解きの手順

  1. 下線部を読む：「朝鮮半島などから移り住む人々が増え、新しい技術や知識が伝えられる」。
  2. 時代は表の左はしで古墳時代と確認。
  3. 「移り住む＋技術を伝える＋古墳時代」の3つがそろえば渡来人で確定。
  4. 指定は漢字3字。字数も一致する。
答え：渡来人

(3) 聖武天皇の都の移りかわり 順番の組合せ選択

前提知識

  1. 聖武天皇の時代は、ききん・伝染病・貴族の反乱が続いた。天皇は都を次々に移し、仏教の力で国を守ろうとした（国分寺・大仏）。
  2. 移った順：平城京→恭仁京→難波宮→紫香楽宮→平城京。大仏づくりは紫香楽宮で始まり、平城京（東大寺）で完成した。
  3. ひっかけの藤原京（持統天皇）・飛鳥宮は、平城京より前の都。時代が合わない。

読み解きの手順

  1. 図の形を見る：平城京 →（a）→ 難波宮 →（b）→ 平城京。a・bは平城京より後の都。
  2. そこで、平城京より前の藤原京・飛鳥宮が入っている選択肢はすべて消す→ア・イ・エ・オ・カが消え、残るのはウだけ。
  3. 検算：ウは a＝恭仁京、b＝紫香楽宮。覚えた順番とも一致。
答え：ウ
コツ：6択でも「時代が合わないことば」を1つ見つければ、いっきに4つ5つ消せる。

(4) 鑑真が創建した寺院 語句記述・漢字指定

前提知識

  1. 鑑真＝唐の高僧。何度も渡航に失敗し、失明しながら753年に来日。日本に正式な戒律（僧になるための決まり）を伝えた。
  2. 鑑真が奈良に開いた寺＝唐招提寺（鑑真の像＝鑑真和上坐像がある）。
  3. 混同しやすい寺：東大寺＝聖武天皇の大仏、法隆寺＝聖徳太子、正倉院＝東大寺の宝庫。

読み解きの手順

  1. 設問は「僧たちが学ぶための場として鑑真が創建した寺院」。
  2. 「鑑真＝戒律＝僧を育てる場所」とつなげる。
  3. 鑑真が来日したときに戒壇を設けたのは東大寺だが、設問は鑑真が「創建した」寺なので唐招提寺。
答え：唐招提寺
書きまちがい注意：「招」を「昭」、「提」を「堤」と書かない。唐・招・提・寺の4字を声に出して書く。

  2. ア「平治の乱で源氏を破った」→○／イ「武士として初の太政大臣」→○／エ「平家納経」→○

(6) 鎌倉時代の焼き物 正しくないもの選択・時代のずれ

前提知識

  1. 下線部⑥は鎌倉時代。この時代、各地で焼き物づくりがさかんになった（瀬戸・常滑・信楽・備前などは「六古窯」とよばれる古い産地）。
  2. 有田焼（伊万里焼）＝佐賀県。豊臣秀吉の朝鮮出兵の際に連れてこられた朝鮮人の陶工によって始まり、17世紀初め＝江戸時代につくられるようになった。
  3. 朝鮮出兵は「焼き物戦争」ともよばれ、有田焼・萩焼・薩摩焼がこのとき始まった系統。

読み解きの手順

  1. 設問は「この時代（鎌倉）の焼き物として正しくないもの」。焼き物の良し悪しではなく時代のずれを探す問題。
  2. イ信楽焼・ウ瀬戸焼・エ備前焼→どれも古くからの産地→○
  3. ア有田焼→始まりは江戸時代→×＝これが答え
答え：ア
見分け方：九州の焼き物（有田・唐津・薩摩）は朝鮮出兵より後。九州の名前が出たら「江戸時代からでは？」と疑う。

(7) 元寇についてのX・Y 正誤の組合せ

前提知識

  1. 元寇＝文永の役（1274）・弘安の役（1281）。執権は北条時宗。御家人は博多湾沿岸に集められ、石塁（防塁）を築いた。
  2. 元軍の集団戦法とてつはう（火薬兵器）に、一騎打ち中心の日本の武士は苦しんだ。
  3. 北条政子が「頼朝公の御恩」を説いて御家人を団結させたのは承久の乱（1221）。元寇より50年ほど前で、しかも相手は朝廷。

読み解きの手順

  1. X「北条政子が御恩をといて団結を訴え…博多湾沿岸に集結」→政子の演説は承久の乱。人物と事件の入れかえ→誤
  2. Y「集団戦術やてつはうに苦しみ、恩賞を得るために命をかけて戦った」→正
  3. X＝誤・Y＝正の組合せを選ぶ→ウ。
答え：ウ
X・Y型はXだけ／Yだけを独立して判定し、答えの記号は最後に見る。両方をまとめて「なんとなく正しそう」で選ばない。

(8) 室町時代の社会についてのX・Y 正誤の組合せ・時代のずれ

(9) 鉄砲が伝わった島 地図で場所を選ぶ

前提知識

  1. 1543年、ポルトガル人を乗せた船が種子島（鹿児島県）に漂着し、鉄砲が伝わった。島主は種子島時堯とされる。
  2. 種子島は九州の南、大隅半島の南東にある細長い島。すぐ西どなりの丸い島が屋久島。
  3. まぎらわしい島の位置：対馬＝九州と朝鮮半島の間、五島列島＝長崎県の西、隠岐＝島根県の北の日本海。

読み解きの手順

  1. まず「鉄砲＝種子島」を思い出し、九州の南を探すと決める。
  2. ア＝対馬（九州の北西・朝鮮半島寄り）→×／イ＝隠岐（中国地方の北の日本海）→×／ウ＝五島列島（長崎県の西）→×
  3. エ＝九州の南にある細長い島で、となりに丸い屋久島がある→種子島→○
答え：エ
島の地図問題は「方角」で半分に絞るのが速い。南の島を聞かれているのに、日本海の島を見に行かない。

(10) キリスト教の広がりと取りしまり 正しくないもの選択

  2. ア「4人の少年をローマ教皇のもとへ」→○／ウ「島原や天草で大規模な一揆」→○／エ「絵踏」→○

(16) 大正時代のできごと 正しくないもの選択・年代

読み解きの手順

  2. ア米騒動＝1918／イ関東大震災＝1923／ウ第一次世界大戦＝1914→すべて大正→○

問6 河上肇の講演が反発された理由 記述6点・100字以上140字以内（最重要）

下線部⑤「沖縄の文化は独自性がある。本土とちがって忠君愛国の考えはうすいものの、それはなげくことではない…」

前提知識（この順で）

  1. 忠君愛国＝天皇に忠義をつくし、国を愛すること。明治から昭和前期にかけて、学校教育で最も重んじられた価値。「忠君愛国がうすい」＝当時は最大級の悪い評価だった、という感覚をつかむのがこの問題の入り口。
  2. 本文より、沖縄県設置後の沖縄の人々の状況は──①王国時代と変わらない重い税、②地租改正が本土より30年遅れた、③参政権も本土より遅れていた＝本土との待遇に差があった。
  3. だからこそ沖縄の人々は、「日本国民」になるための教育（方言の禁止・風俗の改良・改姓改名）を受け入れていた。自分たちの文化を捨ててでも本土並みにあつかわれたかった、ということ。
  4. 河上肇はほめるつもりで「独自性がある」「忠君愛国はうすいが、それはなげくことではない」と言った。しかし言われた側は「愛国心が足りない県だ」と本土に思われることをいちばんおそれていた。ほめことばが、当事者には不利な評価として響いたというすれちがいが答えの核心。

設問文・資料から拾う手がかり

  • 「当時の沖縄の人々がおかれていた状況をふまえたうえで」＝前提知識2・3（待遇の差／同化政策を受け入れていたこと）を必ず書けという指定。ここを書かずに「失礼だと思ったから」だけでは大幅減点。
  • 別紙の【解説】も「下線部⑤の前に書かれている文章が大きなヒントになっています」とはっきり言っている。直前の1文「方言の禁止、風俗の改良、改姓改名が行われました」が答えの前半そのもの。
  • 字数は100字以上140字以内。解答用紙は14字×10行＝140マス、8行目の2マス目のうしろの縦線が100字の目印。8行目の縦線を必ず越えること。模範解答は125字。
  • 文末は「〜から。」（理由を聞かれている）。

答案の組み立て

字数が長いぶん、3つの要素を「努力していた」→「それにもかかわらず」→「おそれた」の順に並べる。この「それにもかかわらず」が接着剤になります。

要素書く内容模範解答の対応部分（計125字）
A
（状況）		沖縄の人々は日本本土との待遇の差をなくしたかった「沖縄の人々は、日本本土との待遇の差をなくすために、」
B
（努力）		そのために旧来の価値を否定し、日本国民となるための政策を受け入れ、忠君愛国を示そうと努力していた（＝方言の禁止・風俗の改良・改姓改名を受け入れていた）「旧来の価値を否定して、日本国民となるための様々な政策を受け入れ、忠君愛国を示そうと努力していた。」
C
（反発の理由）		それなのに「愛国心がうすい」と表現され、本土との待遇改善に影響するとおそれた「それにもかかわらず、日本に対する愛国心がうすいと表現され、日本本土との待遇改善に影響するとおそれたから。」

やりがちな失敗：「沖縄の文化をばかにされたと感じたから」だけで終わる答案。気持ちだけで「待遇」という現実の損得が書けていないので、Cの半分しか取れません。この問題は「悪口を言われて怒った」話ではなく、「本土並みの扱いが遠のく」という実害の話です。

模範解答：沖縄の人々は、日本本土との待遇の差をなくすために、旧来の価値を否定して、日本国民となるための様々な政策を受け入れ、忠君愛国を示そうと努力していた。それにもかかわらず、日本に対する愛国心がうすいと表現され、日本本土との待遇改善に影響するとおそれたから。（125字）［6点］
自分で解くときのチェック：書き終えたら「待遇」ということばが2回入っているかと、8行目の100字の線を越えたかの2点だけ見る。100字に届いていない答案は、Bの「どんな政策を受け入れていたか」が書けていないはず。

設問文・資料から拾う手がかり

  • 「沖縄県が現在おかれている状況をふまえたうえで」＝今の沖縄の事実（基地の集中・経済格差）を必ず1つ以上書けという指定。感想だけの答案は条件違反。
  • 別紙の【解説】も「当時、沖縄県の人々がなぜ本土復帰を求めたのかを、文章中から読み取る必要があります」としている。つまり「昔の願い」は本文から、「今の状況」は知識から持ってくる二段構えの問題。
  • 文末は「〜と思う。」。「かなえられていると思いますか」と聞かれているので、思う／思わない（いえない）をはっきり書く。
  • 「かなえられている」という立場で書いてもよいが、そのときも現在の状況を根拠として示す必要がある。模範解答は「いえないと思う」の立場。

答案の組み立て

要素A（昔の願い）→要素B（今の現実）→要素C（だからこう思う）の3ステップ。この順番を崩さないこと。

要素書く内容模範解答の対応部分
A
（昔の願い）		復帰当時の人々は、ほかの都道府県と同じように平和で豊かな生活を望んでいた「本土へ復帰した当時の沖縄県の人々は、ほかの都道府県の人々と同じように平和で豊かな生活を望んでいた。」
B
（今の現実）		今も米軍基地の多くが沖縄に集中し、経済格差も大きいまま「しかし、現在もなお米軍基地の多くが沖縄県に集中して残され、ほかの都道府県との経済格差も依然として大きいままである。」
C
（結論）		この状況が改善されない限り、願いはかなえられているとはいえないと思う「このような状況が改善されない限り、復帰を望んだ人々の願いはかなえられているとはいえないと思う。」

要素Aが「平和」と「豊かさ」の2つで、要素Bの「基地」と「経済格差」がきれいに1対1で対応しているのがこの模範解答のうまいところ。平和↔基地／豊かさ↔経済格差と対にして書くと、短くても説得力が出ます。

模範解答：本土へ復帰した当時の沖縄県の人々は、ほかの都道府県の人々と同じように平和で豊かな生活を望んでいた。しかし、現在もなお米軍基地の多くが沖縄県に集中して残され、ほかの都道府県との経済格差も依然として大きいままである。このような状況が改善されない限り、復帰を望んだ人々の願いはかなえられているとはいえないと思う。［6点］
自分で解くときのチェック：意見記述では「しかし」を1回使うとうまくいく。「しかし」の前に昔の願い、後ろに今の現実を置けば、要素A・Bが自動的にそろう。
