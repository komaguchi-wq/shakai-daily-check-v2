640-26 コアプラス確認テスト CP1・CP2（説明文から地名／農林水産業の2文正誤）

CP1 全体像 説明文から地名を漢字で 5問（各10点）

語群は無く、説明文の手がかりから地名を漢字で書く。解答らんに「平野」「盆地」「村」「湾」が印刷されているので、答えらんの字で地形の種類が先に決まる。あとは川・山・半島などの固有名詞に丸をつけて県を決め、地名にする。

問丸をつける部品県答え
(1)最上川・酒田山形庄内（平野）
(2)阿武隈川中流・安積疏水福島郡山（盆地）
(3)浅間山・高冷地農業群馬嬬恋（村）
(4)シラス台地・茶・畜産業鹿児島笠野原
(5)下北半島と津軽半島青森陸奥（湾）

今回は5問中4問○。(3)は場所までたどれていて、「嬬」の字で落とした。

CP1 (1) 最上川の下流と酒田の平野 素材文・地名（漢字）

👀 まず見るところ

【素材文】答えらんの「平野」で種類は決まっている。部品は「最上川」「酒田」に丸 → 山形県の日本海側、庄内平野と決まる。

📚 前提知識

  • 最上川は山形県を流れて日本海へ注ぐ。下流の庄内平野は全国有数の米どころ。
  • 河口の酒田は、江戸時代に西廻り航路で米を大坂へ送り出す港として栄えた。

🔍 こう読み解く

  1. 最上川の「下流」＋河口の酒田 → 庄内平野。同じ最上川でも上流側は山形盆地・米沢盆地なので、「下流」の1語で区別できる。
答え：庄内（平野）
今回：庄内 ○。

CP1 (2) 阿武隈川中流と安積疏水の盆地 素材文・地名（漢字）

👀 まず見るところ

【素材文】「阿武隈川中流」だけでは福島盆地とまよう。部品は2つ目の「安積疏水」に丸 → 猪苗代湖の水を引いた福島県の郡山盆地と決まる。似たものが2つあるときは丸を2つ。

📚 前提知識

  • 安積疏水は明治時代、猪苗代湖の水を山の向こうの郡山側へ引いた用水路。水の足りなかった土地で稲作が広がった。
  • 阿武隈川は福島県を北へ流れ、宮城県で太平洋に注ぐ。流れにそって郡山盆地・福島盆地がならぶ。

🔍 こう読み解く

  1. 阿武隈川ぞいの盆地 → 郡山盆地か福島盆地。
  2. 猪苗代湖からの安積疏水 → 郡山盆地。
答え：郡山（盆地）
今回：郡山 ○。

CP1 (3) 浅間山のふもとの高原の村 素材文・地名（漢字）

👀 まず見るところ

【素材文】部品は「浅間山」「高冷地農業」に丸 → 群馬県の嬬恋村（夏のキャベツ）。設問の「漢字で」にも丸。この問は「嬬」の字が書けて初めて点になる。

📚 前提知識

  • 嬬恋村は浅間山の北のふもとの高原。夏もすずしいので、平地の産地が出しにくい夏から秋にキャベツを出荷する（高冷地農業）。
  • 「嬬」は女へん＋需。「つま」の意味をもつ字なので女へん。村の名は、ヤマトタケルが亡くなった妻をしのんだ言い伝えから、とされる。

🔍 こう読み解く

  1. 浅間山（群馬・長野の県境）の山ろく＋高冷地農業＋答えらんの「村」→ 嬬恋村。
  2. 書いたら「女へん」かどうかを見直す。にんべんの「儒」は別の字になる。
答え：嬬恋（村）
今回：「儒恋」×（へんをにんべんで書いた）。知識＝浅間山から嬬恋村まではたどれていて、落としたのは「嬬」の字の形だけ。「嬬＝つま＝女へん」と意味で結びつけて覚え直す。

CP1 (4) シラス台地の畑作と畜産 素材文・地名（漢字）

👀 まず見るところ

【素材文】部品は「シラス台地」に丸 → 鹿児島県。答えらんに「平野」などの字が無いので、代表的なシラス台地の名前笠野原をそのまま書く。

📚 前提知識

  • シラスは火山の噴出物が積もった白っぽい土。水がしみこみやすく稲作に向かないため、さつまいも・茶などの畑作や、ぶた・肉牛などの畜産がさかん。
  • 笠野原は鹿児島県の大隅半島にある台地。用水が引かれてから畑作が広がった。

🔍 こう読み解く

  1. シラス台地＋稲作に不向き＋茶・畜産 → 鹿児島 → 笠野原。
答え：笠野原
今回：笠野原 ○。

CP1 (5) 下北半島と津軽半島の間の湾 素材文・地名（漢字）

👀 まず見るところ

【素材文】部品は「下北半島と津軽半島」に丸 → 2つの半島にはさまれた青森県の陸奥湾と決まる。「ほたて貝」は答え合わせに使う。

📚 前提知識

  • 青森県の北は、東に下北半島、西に津軽半島。その間が陸奥湾で、ほたて貝の養殖がさかん。
  • 貝の養殖は、かき＝広島湾・仙台湾、ほたて貝＝陸奥湾・サロマ湖、と組で区別する。

🔍 こう読み解く

  1. 2つの半島の名前で青森の湾 → 陸奥湾。ほたて貝とも合う。
答え：陸奥（湾）
今回：陸奥 ○。

CP2 全体像 2つの文の正誤 5問（各10点）

答え方の指示「1つなら1、両方正しいなら2、両方誤りなら0」は、「答え＝正しい文の数」と直して余白に書いておく。1文ずつ、すりかえられやすい言葉に丸をつけて文の横に○×を書き、最後に○を数える。

問すりかえられた言葉正しくはすりかえの種類
(1)2文目かんぴょう＝群馬県栃木県場所ちがい
(2)1文目三大穀物＝米・大麦・大豆米・小麦・とうもろこしなかまちがい
(2)2文目1991年に米とオレンジ牛肉とオレンジ品目ちがい
(3)1文目人工の美林に秋田すぎ吉野すぎ（秋田すぎは天然）天然と人工の入れかえ
(4)1文目200カイリ内で数日間＝遠洋漁業沖合漁業用語の入れかえ
(4)2文目成魚まで育てる＝栽培漁業養殖業用語の入れかえ

今回は5問すべて○。

CP2 (1) コシヒカリとかんぴょう 素材文・2文の正誤

👀 まず見るところ

【素材文】1文に丸1つ。2文目の部品「かんぴょう」と「群馬県」→ かんぴょうは栃木県なので×。1文目は○ → 正しい文は1つ。

📚 前提知識

  • 米の品種はコシヒカリの作付けが最も多い。
  • かんぴょう（ゆうがおの実をむいて干したもの）は栃木県が全国の大部分。群馬県の特産はこんにゃくいも。

🔍 こう読み解く

  1. 1文目 ○、2文目 ×（場所ちがい）→ ○は1つ → 1。
答え：1
今回：1 ○。

CP2 (2) 三大穀物と輸入自由化 素材文・2文の正誤

👀 まず見るところ

【素材文】部品は1文目の「大麦、大豆」と2文目の「米と」に丸。三大穀物は米・小麦・とうもろこし、1991年は牛肉とオレンジ → 両方×で0。

📚 前提知識

  • 世界の三大穀物＝米・小麦・とうもろこし。
  • 1991年に輸入が自由化されたのは牛肉とオレンジ。米は国内の生産を守るため、輸入に高い関税をかけている。

🔍 こう読み解く

  1. 1文目 ×（なかまちがい）、2文目 ×（品目ちがい）→ ○は0こ → 0。
答え：0
今回：0 ○。

CP2 (3) 三大美林と森林の木の種類 素材文・2文の正誤

👀 まず見るところ

【素材文】部品は「人工の」と「秋田すぎ」に丸。秋田すぎは天然の三大美林なので1文目は×。2文目は○ → 1。

📚 前提知識

  • 天然の三大美林＝秋田すぎ・青森ひば・木曽ひのき。人工の三大美林＝天竜すぎ・尾鷲ひのき・吉野すぎ。
  • 日本では、すぎ・ひのきなどの針葉樹を多く植林してきたため、森林の中の針葉樹の割合が高い。

🔍 こう読み解く

  1. 天竜すぎ・尾鷲ひのきまでは人工の三大美林で合っている。3つ目だけが天然の秋田すぎにすりかわっている。
  2. 1文目 ×、2文目 ○ → 1。
答え：1
今回：1 ○。

CP2 (4) 漁業の種類の定義 素材文・2文の正誤

👀 まず見るところ

【素材文】定義の文は、説明の部品に丸。「200カイリ内で数日間」＝沖合漁業、「成魚になるまで育てる」＝養殖業。どちらも用語がすりかわっている → 0。

📚 前提知識

  • 沿岸漁業＝日帰りできる近い海。沖合漁業＝200カイリ内で数日間。遠洋漁業＝200カイリの外の遠い海で数か月。
  • 養殖業＝いけすなどで出荷する大きさまで育てる。栽培漁業＝卵から稚魚まで育てて海に放流し、大きくなってからとる。

🔍 こう読み解く

  1. 1文目：数日間なら沖合漁業 → ×。
  2. 2文目：成魚まで育てる（放流しない）なら養殖業 → ×。○は0こ → 0。
答え：0
今回：0 ○。
コツ：栽培漁業と養殖業は「放流するかどうか」の1点で分ける。

CP2 (5) まぐろのとり方と潮目 素材文・2文の正誤

👀 まず見るところ

【素材文】部品は「はえなわ」と「潮目」「三陸海岸の沖合」に丸。どちらも教科書どおりの組み合わせで、すりかえは無い → 2。

📚 前提知識

  • はえなわ漁＝長いなわにたくさんの針をつけてまぐろなどをとる。
  • 潮目＝寒流（親潮）と暖流（黒潮）がぶつかる所。プランクトンが多く魚が集まる。三陸海岸の沖が代表。

🔍 こう読み解く

  1. 1文目 ○、2文目 ○ → ○は2つ → 2。
答え：2
今回：2 ○。

CP2 まとめ CP1 4/5・CP2 5/5・合計90点

  • CP1は5問とも川・山・半島の名前から場所までたどれている。落としたのは(3)の「嬬」の字だけ。
  • CP2はかんぴょう（栃木）・人工と天然の美林・沖合と遠洋・養殖と栽培のすりかえを全部見ぬけた。
  • 覚え直し：嬬恋村の「嬬」は女へん（つまの意味）。
