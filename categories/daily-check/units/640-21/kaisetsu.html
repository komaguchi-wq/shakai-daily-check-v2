演習1 (1)A 金属の道具が伝わった時代 素材文・空らん

👀 まず見るところ

【素材文】部品は「金属の道具が伝わった」に丸。金属器（鉄器・青銅器）が大陸から来たのは稲作と同じ弥生時代、とその場で決める。

📚 前提知識

  • 縄文＝土器・石器。弥生＝稲作と金属器（鉄器・青銅器）が大陸・朝鮮半島から伝わる。

🔍 こう読み解く

  1. 次の文「鉄器と［B］器」「中国大陸や朝鮮半島から持ちこまれた」も弥生の話としてそろう → 弥生。
答え：弥生
今回：弥生 ○

📚 前提知識

🔍 こう読み解く

答え：青銅

演習1 (5) 平城京の時代の貴族の生活 素材文・正しいもの

👀 まず見るところ

【素材文】部品は「平城京に都が置かれた時代」。これを「奈良時代＝律令・税が都へ」と直して書く。すると寝殿造（平安）・書院造（室町）が消え、税の米や布を受け取るエが残る。

📚 前提知識

  • 平城京は710年から。律令のしくみで、農民の税（米・布・特産物）が都に集まり、貴族や役人は位に応じてそこから給料を受け取った。
  • 寝殿造＝平安の貴族の屋敷。書院造＝室町（銀閣のころ）。荘園が広がるのは743年の墾田永年私財法よりあと。

🔍 こう読み解く

  1. イ 寝殿造 → 平安の時代ちがい ×。ウ 書院造・茶の湯 → 室町の時代ちがい ×。
  2. ア「荘園を武力で獲得」→ 奈良の貴族は武力で土地を取る立場ではない ×。
  3. エ 税の米や布を給料として受け取る → 律令のしくみそのもの ○。
答え：エ
今回：ア ×（別紙の答えはエ）。原本の(5)らんに○も×もなく、通っている赤線は(9)の○の続きだけ。合計42点は(1)Dと(6)の4点×2だけを引いた数なので、採点と正誤表の記録では正解あつかいになっている。部品の形を直さなかった＝「平城京」を「奈良時代・律令」に書きかえないまま選んだ。次は下線部の横に時代名を書いてから選択肢へ。
コツ：「〜の時代の貴族」は、屋敷の名前で時代を切る。寝殿造＝平安、書院造＝室町。

演習3 (7) 裁判官を罷免するかどうかの裁判 素材文・記号

👀 まず見るところ

【素材文】部品は「図中のお」（国会→裁判所）と「罷免するかどうか」に丸。国会が裁判官をやめさせるかを決める裁判＝弾劾裁判と決まる。

📚 前提知識

  • 弾劾裁判所は国会に置かれ、国会議員が裁判官となって、ふさわしくない行いをした裁判官を裁く。

🔍 こう読み解く

  1. 民事・刑事・行政裁判は裁判所が行うふつうの裁判。国会→裁判所の矢印に合わない。
  2. 残るエ弾劾裁判。
答え：エ
今回：エ ○

演習3 (8) 一票の格差と「法の下の□」 素材文・漢字2字

👀 まず見るところ

【素材文】部品は「有権者数と議員定数の比率に著しい不均衡」と「法の下の」に丸。1票の重さがちがう＝みんなが同じに扱われていない、とつながり、平等と決まる。

📚 前提知識

  • 日本国憲法第14条「すべて国民は、法の下に平等」。選挙区によって1票の重さがちがう「一票の格差」は、これに反するとして裁判になってきた。

🔍 こう読み解く

  1. 不均衡（かたよっている）の反対の状態が憲法の保障 → 平等。
答え：平等
今回：平等 ○

演習3 (9)X 内閣から国会への矢印 資料問題・当てはまらなければ×

👀 まず見るところ

【資料問題】部品は矢印Xの向き「内閣→国会」と、聞かれ方「当てはまるものがない場合は、×」に丸。選択肢6つに「内閣が国会にすること」があるかを1つずつ見る。

📚 前提知識

  • 内閣→国会は衆議院の解散と国会の召集。ア「内閣総理大臣の指名」は逆向き（国会→内閣）。

🔍 こう読み解く

  1. ア〜カのうち、内閣がするのはイ・オ・カ。オは内閣の中の話、イ・カは裁判所へ向かう → Xではない。
  2. ウ国民投票・エ国民審査は国民がするもの。
  3. 当てはまるものがない → ×。
答え：×
今回：エ ×。エ国民審査は国民→裁判所（Y）の矢印。部品を拾えなかった＝Xの矢印の向き「内閣→国会」を図に書きこまず、選択肢から選んでしまった。「×と答える場合がある」の指示にも丸をつけておく。

演習3 (9)Y 国民から裁判所への矢印 資料問題・記号

👀 まず見るところ

【資料問題】部品は矢印Yの向き「国民→裁判所」に丸。国民が裁判官を直接チェックするしくみ＝国民審査と決まる。

📚 前提知識

  • 最高裁判所裁判官の国民審査：衆議院議員総選挙のときに行い、やめさせたい裁判官に×をつける。

🔍 こう読み解く

  1. 国民がするのはウ国民投票とエ国民審査。国民投票は憲法改正のときで裁判所とは関係ない → エ。
答え：エ
今回：エ ○

演習3 (9)Z 内閣から裁判所への矢印 資料問題・順不同・完答

👀 まず見るところ

【資料問題】部品は矢印Zの向き「内閣→裁判所」と、聞かれ方「1つずつとは限りません」に丸。裁判官を決める側が内閣なので、裁判官についての選択肢を2つとも拾う。

📚 前提知識

  • 最高裁判所長官は内閣が指名し天皇が任命する。それ以外の裁判官は内閣が任命する。

🔍 こう読み解く

  1. イ「最高裁判所長官の指名」、カ「最高裁判所長官以外の裁判官の任命」。どちらも内閣がする。
  2. オ「国務大臣の任命」は首相が内閣の中でするもので、裁判所へは向かない。答えはイとカの2つ。
答え：イ・カ（順不同・完答）
今回：イカ ○
