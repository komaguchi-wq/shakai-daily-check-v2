演習1 全体像 史料読解 10問（50点）

2005年度 洗足学園中 第3回 改題

史料は、江戸時代の人物が「天下の権力がだれの手にうつってきたか」を平安時代から順にたどった文章。段落ごとに主役が1人（1つの家）ずつ入れかわるので、読みながら余白に時代の名前を書きこんでおくと、下線部の問いがすべてこの表の上で解ける。

史料の段落主役時代・できごと問い
光孝天皇・関白藤原氏摂関政治（平安）(10)の手がかり
堀河〜安徳の97年間上皇院政（1086〜・平安の終わり）(3)
源頼朝・承久の乱後112年源氏・北条氏鎌倉幕府（1221承久の乱→1333滅亡）(4)(5)
④が政治、尊氏がそむく後醍醐天皇建武の新政→南北朝(6)
子孫が続いて十数代足利氏室町幕府（15代）(7)(8)
およそ10年間／およそ15年織田氏・豊臣氏1573義昭追放→1582信長の死／秀吉が関白(9)(10)

選択肢の問題は、ほとんどが「時代ちがい」「人物ちがい」のすりかえ。史料の年数（97年間・112年・10年間）と空らんの前後の語が、どの時代の話かを教えてくれる。今回は合計31点（原本の合計欄）。

演習1 (1) 史料を書いた人物 人物の説明・正しいもの

👀 まず見るところ

問題文の1行目「江戸時代のある人物が書いた」と、史料の最後「ついに徳川氏の時代となりました」。筆者は江戸時代の人。つまり選択肢の中から江戸時代の人物を1人さがせばよい。

📚 前提知識

  • ウは新井白石。6代・7代将軍を助けた「正徳の治」で、貨幣の質をもとにもどし、長崎貿易で金銀が出ていくのをおさえた。この史料は白石の『読史余論』とされる。
  • アは足利義満（室町）、イは北条義時（鎌倉。姉は北条政子）、エは北条泰時（鎌倉。御成敗式目）。

🔍 こう読み解く

  1. 「江戸時代の人物」と書きこんでから選択肢を読む。
  2. ア・イ・エの人物は、どれも史料の中に出てくる時代（鎌倉・室町）の人。自分より後の徳川氏の時代まで書くことはできない。
  3. ウには「長崎貿易」とある。長崎での貿易を幕府が管理したのは江戸時代。ここで時代が決まる。
答え：ウ
今回：エ ×。余白にアは「足利義満」、エは「北条康時」（正しくは泰時）と人物名まで書けていた。人物は分かっていたので、次は選択肢に入る前に問題文の「江戸時代の人物」に線を引き、鎌倉・室町の人を先に外そう。

演習1 (2) 史料より前のできごとの並べかえ 年代整序・完答

👀 まず見るところ

設問の「この史料に書かれている時代よりも前」。史料は藤原氏（平安）から始まるので、4つとも平安より前、弥生〜奈良の話になる。1つずつ年か時代を横に書くのが入口。

📚 前提知識

  • イ 奴国の王が金印を受ける＝57年（弥生）。エ 豪族に「臣」「連」の姓＝氏姓制度（古墳時代・大和政権）。
  • ウ 中大兄皇子・中臣鎌足が蘇我氏をたおす＝645年（大化の改新）。ア 墾田永年私財法＝743年（奈良）。

🔍 こう読み解く

  1. 年が書けるものから書く：イ57、ウ645、ア743。
  2. 年のないエは「臣・連」から古墳時代。57年と645年のあいだに入る。
  3. イ→エ→ウ→ア。2番目がエ、4番目がア。完答なので2つそろえて答える。
答え：2番目 エ　4番目 ア
今回：2番目エ・4番目ア ○。余白に743・57・645・古墳と書き、「イエウア」と並べてから答えている。並べかえのお手本どおりの手順。

演習1 (3) 院政のころの様子 時代の様子・ふさわしくないもの

👀 まず見るところ

下線部①の前「堀河天皇から安徳天皇まで、97年間は政治は上皇が」。上皇が政治を行う＝院政、平安時代の終わりの約100年。設問は「ふさわしくないもの」なので、平安の終わりではない文を1つさがす問題になる。

📚 前提知識

  • 院政は1086年、白河上皇から。上皇は源氏・平氏の武士を重く用い、平清盛が力をのばした。
  • 大和絵の絵巻物『源氏物語絵巻』『鳥獣戯画』は平安の終わりごろの作品。興福寺・延暦寺の僧兵が朝廷に要求をおしつけた（強訴）のもこのころ。
  • 土倉・酒屋は室町時代の金融業者。1428年の正長の土一揆でおそわれた。

🔍 こう読み解く

  1. 各文の時代を決める語に線を引く：ア「土倉・酒屋」、イ「上皇・武士」、ウ「絵巻物」、エ「僧兵」。
  2. イ・ウ・エは院政のころの話としてそのまま合う。
  3. アの土倉・酒屋は室町時代の語。時代ちがいのすりかえなので、アがふさわしくない。
答え：ア
今回：エ ×。余白に1086・1428・754と年を書いていて、1086（院政の始まり）は正しく思い出せていた。1428が正長の土一揆のことなら、それは「土倉・酒屋がおそわれた年」なので、アの語に結びつければアが室町だと決まった。エは興福寺という古い寺の名前が出てくるが、僧兵で要求を通そうとしたのは平安の終わりの話。次は年を書いたら、それがどの選択肢の語のことかまで結びつけよう。
コツ：「ふさわしくないもの」は、1つだけ時代がずれている語をさがす。寺の名前より「土倉・酒屋」「僧兵」のようなその時代にしか出てこない語を見る。

演習1 (4) 守護の任務 用語説明の記述

👀 まず見るところ

設問の「守護と地頭が重要な役割を果たしました。このうち、守護の任務を」。地頭と区別できる書き方が求められている。守護と地頭のちがいは「どの単位に置かれたか」と「何の仕事か」の2つ。

📚 前提知識

  • 守護＝国ごとに1人置かれ、御家人を指揮して軍事・警察にあたる（京都を守る大番役の催促、謀反人・殺害人の取りしまり）。
  • 地頭＝荘園や公領ごとに置かれ、年貢の取り立てや土地の管理にあたる。

✍️ 答案の組み立て

  1. 要素A（置かれた単位）：国ごとに置かれた。
  2. 要素B（仕事）：主に軍事や警察の仕事にあたった。
模範解答：（例）国ごとに置かれ、主に軍事や警察の仕事にあたった。
今回：「国をかん視する。」△。「国」という単位の手がかりは入っているが、「かん視する」だけでは何を見はるのか分からず、地頭との区別にもならない。「軍事」「警察」の2語を入れれば要素Bがそろった。
コツ：守護と地頭はセットで覚える。守護＝国・軍事警察／地頭＝荘園・年貢。

演習1 (5) モンゴルが2度日本を襲撃した出来事 知識問題

元寇。フビライの元が1274年（文永の役）と1281年（弘安の役）の2度せめてきた。執権は北条時宗。史料の「承久の乱後112年」（1221年→1333年）の中に入る。
答え：元寇
今回：元寇 ○

演習1 (6) 空らん④の天皇 知識問題

後醍醐天皇。1333年に鎌倉幕府をたおして建武の新政を行ったが、足利尊氏がそむき、吉野へのがれた（南朝）。尊氏が立てた光明天皇が北朝で、南北朝時代になる。史料の「尊氏がそむいて」「光明天皇を即位させて」がそのままの手がかり。漢字指定。
答え：後醍醐天皇
今回：後醍醐天皇 ○

演習1 (7) 室町時代の様子 時代の様子・ふさわしくないもの

👀 まず見るところ

下線部⑤「自らは幕府を開き、子孫が続いて十数代」。主語は足利尊氏なので室町幕府（15代）。(3)と同じく「ふさわしくないもの」＝室町ではない文をさがす。

📚 前提知識

  • 室町時代の村：農民が惣をつくり、寄合で決まりを決めた。団結して土一揆を起こす（1428年 正長の土一揆など）。馬借は運送業者。
  • 二毛作は鎌倉時代に西日本で始まり、室町時代に東日本へ広まった。
  • 室町時代の商工業者の組合は座。株仲間は江戸時代の組合で、田沼意次が認め、水野忠邦が解散させた。

🔍 こう読み解く

  1. ア 惣・寄合、イ 二毛作の広がり、ウ 馬借・一揆は、どれも室町時代の話。
  2. エの「株仲間」だけが江戸時代の語。室町なら「座」になるはず。語のすりかえなので、エがふさわしくない。
答え：エ
今回：エ ○。「座」と「株仲間」の区別ができている。

演習1 (8) 下線部⑥の将軍 人物名・漢字指定

👀 まず見るところ

下線部⑥の直前「足利氏のあとに、織田氏が勢いを増して、⑥将軍を廃して」。織田氏が廃した将軍は、そのとき将軍だった人＝足利氏の最後の将軍。答えの姓は「足利」と決まる。

📚 前提知識

  • 1573年、織田信長は15代将軍足利義昭を京都から追放した。これで室町幕府は滅亡。
  • 北条早雲は関東で勢力を広げた戦国大名（小田原を本拠にした後北条氏の祖）で、将軍にはなっていない。

🔍 こう読み解く

  1. 「将軍」と書いてあるので、候補は征夷大将軍になった人だけ。戦国大名は外れる。
  2. 「足利氏のあとに」→ 廃されたのは足利氏の将軍。信長と同じ時代の足利将軍は義昭。姓名とも漢字で書く。
答え：足利義昭
今回：北条早雲 ×。北条早雲は将軍ではないので、「将軍とはだれか」の時点で外れる。次は下線部の直前の「足利氏のあとに」から読もう。姓が足利になることは史料だけで決まる。

演習1 (9) 織田信長の10年間の政策 人物の政策・ふさわしいもの

👀 まず見るところ

設問の「この10年間に織田信長が行った政策」。4つの政策を信長か、秀吉かに仕分けるのが入口。信長と秀吉の政策はよく入れかえて出題される。

📚 前提知識

  • 信長：安土城下で楽市・楽座。1571年に比叡山延暦寺を焼き討ち。キリスト教は保護した。
  • 秀吉：太閤検地（全国の田畑を測量）、バテレン追放令（宣教師の追放）。
  • 高野山金剛峯寺は空海が開いた真言宗の寺。

🔍 こう読み解く

  1. ウ 検地、エ 宣教師の追放は秀吉 → 人物ちがいで×。
  2. イは焼き討ちの相手がすりかえられている。信長が焼いたのは延暦寺で、金剛峯寺ではない → ×。
  3. 残ったア 楽市・楽座が信長の政策 → ○。
答え：ア
今回：ア ○。イの寺の名前のすりかえにもひっかからなかった。

演習1 (10) 空らん⑧の地位 語句選択

👀 まず見るところ

空らんの前「豊臣氏は、先人の用いた知恵で自ら⑧となり」。先人とはだれか。史料の最初の段落に戻ると「関白をおいたりおかなかったり」「藤原氏」とある。昔の藤原氏と同じ地位についた、という意味になる。

📚 前提知識

  • 豊臣秀吉は1585年に関白、翌年に太政大臣となり、朝廷の地位で天下を治めた。征夷大将軍にはなっていない。
  • 摂政は天皇が幼いときなどに代わって政治を行う役。大老は江戸幕府の臨時の最高職。

🔍 こう読み解く

  1. ウ 大老は江戸幕府の役職なので、秀吉の時代にはない → ×。
  2. イ 征夷大将軍は幕府を開く人の地位で、秀吉はならなかった → ×。
  3. 摂政と関白はどちらも藤原氏だが、史料の冒頭に出てくるのは「関白」。エ 関白。
答え：エ
今回：エ ○。

演習2 (1)A・(2)A 琵琶湖から大阪湾へ 河川名＋地図

👀 まず見るところ

書き出しの「日本最大の湖を源流に持ち」。日本最大の湖は琵琶湖で、琵琶湖から流れ出る大きな川は1本しかない。

📚 前提知識

  • 淀川：琵琶湖から出た流れが宇治川となり、桂川・木津川と合流して大阪湾に注ぐ。
  • 京都（都）と大阪湾（瀬戸内海）を結ぶ水の道として、昔から船が行き来した。

🔍 こう読み解く

  1. 「日本最大の湖」＋「宇治川・木津川・桂川」→ 淀川。
  2. 地図では、近畿の内陸から南西へ下って大阪湾に出る川を探す。伊勢湾に出るサ・シではなく、ス。
答え：(1) 淀川　(2) ス
今回：(1) 淀 ○　(2) ス ○。

演習2 (1)B・(2)B 流域面積日本一 河川名＋地図

👀 まず見るところ

「日本最大の流域面積」と「銚子から太平洋に注ぐ」。「最長」ではなく「流域面積」と書いてある点に注意する。

📚 前提知識

  • 利根川：流域面積は日本一、長さは信濃川に次ぐ2位。「最長＝信濃川」「流域面積＝利根川」を組で覚える。
  • 江戸時代に、江戸を洪水から守るため流れを東へ付けかえ、銚子で太平洋に出るようになった。下流の霞ヶ浦周辺は水郷とよばれる。

🔍 こう読み解く

  1. 「流域面積日本一」「銚子」「水郷」→ 利根川。
  2. 地図では、関東平野を横切って千葉県の東の端（銚子）に出る川 → キ。
答え：(1) 利根川　(2) キ
今回：(1) 利根 ○　(2) キ ○。

演習2 (1)C・(2)C 日本最長の川 河川名＋地図

👀 まず見るところ

「上流を千曲川といい」。上流と下流で名前が変わる川は、この言葉だけで決まる。「越後平野」「日本海」「日本最長」は答え合わせに使う。

📚 前提知識

  • 信濃川：長野県では千曲川とよばれ、新潟県に入って信濃川となり、越後平野を通って日本海に注ぐ。長さは日本一。

🔍 こう読み解く

  1. 「千曲川」「越後平野」→ 信濃川。
  2. 地図では、本州の中央から北へ向かい新潟の海岸に出る川 → ク。太平洋側へ出るキと向きが逆になっている。
答え：(1) 信濃川　(2) ク
今回：(1) 信濃 ○　(2) ク ○。

演習2 (1)D・(2)D 有明海に注ぐ九州の川 河川名＋地図

👀 まず見るところ

「筑紫平野」と「有明海」。九州の北部で、この2つを両方ふくむ川は筑後川。

  • クリーク：筑紫平野の低い土地に網の目のようにほられた水路。かんがい用水や排水に使われてきた。

🔍 こう読み解く

  1. 「筑紫平野」「有明海」「クリーク」→ 筑後川。
  2. 地図では、九州北部を東から西へ流れて有明海に出る川 → テ。中国地方のツと取りちがえないよう、九州かどうかを先に確かめる。
答え：(1) 筑後川　(2) テ

演習2 (1)E・(2)E 東北一の川 河川名＋地図
